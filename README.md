## 🎯 Objetivo do Projeto

Este repositório documenta um plano estratégico focado em conquistar o primeiro emprego na área de tecnologia. A prioridade máxima é a atuação como Desenvolvedora Back-End, unindo a preferência por lidar com código e a vontade de criar produtos. O plano também prevê uma expansão futura de conhecimentos para a área de Inteligência Artificial.

## 📁 Estrutura do Repositório

O repositório está dividido em dois módulos principais de mentoria:

* **Agent 1 - Entrevistador de carreira em tecnologia**: Contém o perfil detalhado e a avaliação de carreira. A recomendação principal é atuar no Back-End, com a Engenharia de IA e o desenvolvimento Full-Stack como alternativas. O escopo leva em consideração um ritmo sustentável de estudos de 2 horas por semana.
* **Agent 2 - Planejador de Carreiras**: Apresenta um roadmap de 120 dias focado na formação de uma Desenvolvedora Back End Jr, indo da base teórica à preparação para processos seletivos.

## 🗺️ Roadmap de Desenvolvimento (120 Dias)

O planejamento está dividido em quatro fases essenciais de evolução técnica:

* **Mês 1 (Fundamentos)**: Revisão de lógica de programação e introdução a bancos de dados SQL.
* **Mês 2 (Prática)**: Criação da primeira API REST, compreendendo rotas HTTP e implementando um CRUD completo conectado ao banco de dados.
* **Mês 3 (Portfólio)**: Integração de API com banco de dados, documentação de endpoints utilizando Swagger e publicação do projeto finalizado no GitHub.
* **Mês 4 (Preparação)**: Revisão focada em estruturas de dados, resolução de exercícios de lógica e simulação de entrevistas técnicas e comportamentais.

## 🛠️ Tecnologias e Core Skills

As ferramentas e linguagens mapeadas para o desenvolvimento das atividades incluem:

* **Linguagens e Frameworks**: Java ou Python, utilizando Spring Boot ou Django.
* **Bancos de Dados**: PostgreSQL, dominando os conceitos e consultas em ambientes relacionais e não relacionais.
* **Habilidades Essenciais**: Estruturas de dados, lógica de programação e versionamento de código via Git.

## 💻 Projeto de Destaque no Portfólio

* **API de Gerenciamento de Tarefas**: Construção de uma API focada em um CRUD de tarefas. O principal diferencial técnico que demonstra maturidade no projeto é a implementação de um sistema seguro de login e autenticação, utilizando JWT ou sessões.
